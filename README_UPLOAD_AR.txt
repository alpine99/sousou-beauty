نسخة Sousou Beauty FLAT

هذه النسخة مخصصة لحالتك الآن:
- كل الصور والملفات موجودة مباشرة في الصفحة الرئيسية للمستودع.
- لا تحتاج مجلد assets.
- ارفع كل الملفات كما هي إلى GitHub في نفس المكان الظاهر بالصورة.
- وافق على Replace للملفات القديمة.
- اضغط Commit changes.
- انتظر دقيقة ثم افتح http://sousoubeauty.com

ملاحظة:
مشكلة Not Secure ليست من الملفات. HTTPS يحتاج أن تصبح شهادة GitHub جاهزة ثم تفعيل Enforce HTTPS من Settings > Pages.
